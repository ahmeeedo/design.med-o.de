## Overview

A Button starts an action on the current page – save, send, delete, open a dialog. Its label is a verb that says what happens. It is built on React Aria, so it works the same with mouse, touch, keyboard and screen readers.

## Formatting

### Anatomy

![A Save changes button with an icon. Marker 1 points to the container, 2 to the icon before the label, 3 to the label.](/spec/button/anatomy.svg)

1. Container – the clickable area. Its color comes from the variant.
2. Icon (optional) – before or after the label. Decorative.
3. Label – a verb, one line.

### Sizes

md is the default. Use one size per group of buttons.

![The three button sizes side by side: sm 32 px, md 40 px and lg 48 px high, each with a redline for its height.](/spec/button/sizes.svg)

| Size | Height | Use for |
| --- | --- | --- |
| sm | 32 px | Dense areas: toolbars, tables, card headers. |
| md | 40 px | The default for pages, forms and dialogs. |
| lg | 48 px | Touch-first layouts and large calls to action. |

### Alignment and spacing

Group related buttons in a Button group: 8 px apart (`space-2`), all the same size, at most one primary. The main action sits at the end of the reading path.

![A Button group with Delete on the left and Cancel and Save on the right. A redline marks the 8 px gap between Cancel and Save.](/spec/button/spacing.svg)

- Footer of forms, dialogs and sheets: right-aligned, primary on the right, a destructive action on the far left.
- Content (hero, teaser, empty state): left-aligned, primary first.
- Below 640 px: stacked, full width, primary on top.
- More than three actions: move the rest into an overflow menu.

## Content

| Element | Text style | Rule |
| --- | --- | --- |
| Label | `label-md` | Sentence case, 1–3 words, starts with a verb: “Save changes”. |
| Label (lg) | `label-lg` | Same rules – lg only changes the size. |
| Pending label | `label-md` | Says what is happening: “Saving…”. |
