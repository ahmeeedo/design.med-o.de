## Surfaces

At most three levels: page → container → inset.

| Level | Token | For |
| --- | --- | --- |
| Page | `surface/canvas` | The page background. |
| Container | `surface/default` | Cards, inputs, panels. |
| Inset | `surface/subtle` | Table headers, hover rows, code blocks. |
| Floating | `surface/raised` | Dropdowns, dialogs, popovers – always with elevation. |

## Text on backgrounds

Use only these combinations. Each pair reaches 4.5 : 1 in Light and Dark.

| Background | Text | Checked |
| --- | --- | --- |
| `surface/canvas, default, raised, subtle` | `text/primary, text/secondary` | <Badge tone="success" size="sm">≥ 4.5 : 1</Badge> |
| `surface/brand-subtle, brand-muted` | `text/primary, text/secondary` | <Badge tone="success" size="sm">≥ 4.5 : 1</Badge> |
| `surface/brand-bold` | `text/on-brand, text/on-brand-secondary` | <Badge tone="success" size="sm">≥ 4.5 : 1</Badge> |
| `surface/inverse` | `text/inverse, text/inverse-secondary` | <Badge tone="success" size="sm">≥ 4.5 : 1</Badge> |
| `action/primary, -hover, -pressed` | `text/on-action` | <Badge tone="success" size="sm">≥ 4.5 : 1</Badge> |

## Brand surfaces

brand-subtle highlights an area and keeps the normal text colors. brand-bold is for heroes and calls to action and takes only the on-brand text.

## Light and Dark

Every semantic token switches with the theme. Design once in Light; Dark follows.

- Check every screen in both themes before handoff.
- Don’t add colors that exist only in Dark – change a token instead (Guides › Theming).
- Images and illustrations may need their own Dark version; colors don’t.
