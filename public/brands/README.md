# Brand logos

The Updates page shows a brand's logo only when the brand's own kit allows this use: a logo next to a link to the
brand's product or content. Every other brand shows its name as text. Each file comes unchanged from the official kit,
except where a note below says otherwise. Never recolor a logo; use the kit's own variant for Dark.

Checked on November 15, 2026. Check again before you add a logo or change how one is used.

## Logos in use

### GitHub

- Files: `github.svg` and `github-white.svg` (Dark), from `GitHub Logos/SVG/GitHub_Invertocat_Black.svg` and
  `GitHub_Invertocat_White.svg` in https://brand.github.com/GitHub_Logos.zip.
- Terms: https://brand.github.com/foundations/logo
  - "Use a permitted GitHub logo to link to GitHub."
  - "Use the Invertocat logo as a social button to link to your GitHub profile or project."
  - "Do not modify the permitted GitHub logos, including changing the color, dimensions, or combining with other words
    or design elements."
- Conditions: black or white only, never recolored. Less prominent than the med.o brand. Next to a link to GitHub.

### Storybook

- File: `storybook.svg`, from https://github.com/storybookjs/brand (`icon/icon-storybook-default.svg`).
- Terms: the repository README says "Feel free to use and customize these assets for your articles, talks, addons,
  websites, and anything else you can think of."
- License: MIT License, Copyright (c) 2017 Storybooks. Full text:
  https://github.com/storybookjs/brand/blob/main/LICENSE

### Figma

- File: `figma.svg`, from `Figma Brand Assets/Figma Icon (Full-color)/Figma Icon (Full-color).svg` in the "Download
  our logos" ZIP on https://www.figma.com/using-the-figma-brand/.
- Change: the canvas is cropped to the mark (`viewBox="312 340 400 600"` instead of `0 0 1024 1280`). The paths and
  colors are unchanged.
- Terms: https://www.figma.com/using-the-figma-brand/
  - "You can use the word "Figma" and our logos to link to Figma pages and content."
  - "Your own marks and branding should be larger and more prominent than the Figma marks."
- Conditions: no change to the mark. Next to a link to Figma content. No implied affiliation or endorsement.

## Names as text

### Google Chrome

A Google product icon needs approval through the Partner Marketing Hub. Plain text in an informational context is
allowed. Source: https://about.google/brand-resource-center/guidance/

### Microsoft Edge

The Edge logo needs a trademark use license. Source: the Microsoft Edge trademark guidelines (February 2026), linked
from https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks

### Safari

Apple's logos and icons need an express written trademark license. Source:
https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html

### Firefox

For a compatibility statement, the open-source section of the policy asks for words, not logos: "State in words (not
using logos or images) that your product "works with" or "is compatible" with certain Mozilla software products".
Source: https://www.mozilla.org/en-US/foundation/trademarks/policy/

### Samsung Internet

Samsung publishes no usage terms or kit for the Samsung Internet logo.

### npm

"The npm Logos signify us, or a special relationship with us, and you may use them only with our permission." The
policy also asks for the notice "npm is a registered trademark of npm, Inc." in materials that refer to npm. Source:
https://docs.npmjs.com/policies/logos-and-usage
